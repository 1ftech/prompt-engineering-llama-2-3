# Prompt Engineering with Llama 2 & 3

This repository contains my projects from the **Prompt Engineering with LLaMA 2 & 3** specialization by **DeepLearning.AI**. The project explores the fundamentals and advanced techniques of prompt engineering for Meta’s LLaMA models, with hands-on examples and practical use cases.

## 📚 Project Overview

Learn how to:
- Understand the capabilities and limitations of LLaMA 2 & 3 models
- Design effective prompts for various NLP tasks
- Implement few-shot, zero-shot, and chain-of-thought prompting
- Use LLaMA in retrieval-augmented generation (RAG) setups
- Evaluate and refine prompt-based outputs

## 🛠️ Tools & Technologies
- 🐍 Python  
- 🤗 Hugging Face Transformers  
- 🦜 LangChain  
- Meta’s LLaMA 2 & 3 models (via APIs or local deployment)  
- Jupyter Notebooks

## ✅ Skills Gained
- Prompt engineering fundamentals
- Working with open-source LLMs (LLaMA 2 & 3)
- Prompt tuning and refinement strategies
- RAG techniques with custom data
- Output evaluation and improvement
